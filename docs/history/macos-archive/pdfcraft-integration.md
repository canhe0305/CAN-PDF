# PdfCraft 接入记录

日期：2026-10-08。上游固定提交：`d3db99818f533a531dbcd469b2ac71ba35c0d3ec`。
来源：https://github.com/storytold/pdfcraft （原名 PrintCraft）。

## 本次范围

- 标准 PDF 高亮、下划线、删除线和便笺。阅读模式选择文字后打开“文档工具”；便笺可以点击页面放置。批注列表支持修改文字和删除，锁定批注保持保护。
- 新增和已有批注的修改进入 Revision，与其他修改共享撤销、重做和草稿恢复。输出使用 `/Annots`、`/Contents`、`/QuadPoints` 和外观流；不是绘制在页面上的伪批注。
- 合并当前编辑结果和所选 PDF，当前文档在前，追加文件按文件名排序。提取支持 `1-3, 5`；拆分按每份页数写入所选目录。
- 图片压缩可选分辨率、质量。保留结构标签、书签、表单和批注；不支持的图片格式跳过。如果总文件没有缩小，输出原快照。
- XFDF/FDF 批注导入、导出。当前不开放表单值导入；中文 FreeText 文本框的导入也尚未开放，避免上游默认字体导致缺字。中文便笺内容和文字标记内容已验证。
- 页面整理、压缩和批注交换导出均为独立副本；不改变当前文档历史。输出必须为新文件名；拆分名带随机前缀避免覆盖。中途失败会报告已经写出的文件。

## 接入方式

仅纳入所需 Rust 模块及依赖，保留现有 React、PDF.js、PDFium、pdf-lib。源码在 `src-tauri/vendor/pdfcraft`；导入脚本固定提交并记录包装变更。没有纳入 egui、hayro 或上游整套应用。

新增入口在 `src-tauri/src/pdfcraft.rs`。本机任务在线程池执行。PDF 在 WebView 边界使用二进制请求和响应，避免大字库 PDF 转成 JSON 数字数组。批注只在事务提交后重建页面预览，键入便笺内容不触发整份 PDF 重写。

写入次序：现有引擎处理原文、填写和新增对象 → PdfCraft 从初始源重放批注操作 → 应用页面旋转、删除和排序。批注存在时，先延后 pdf-lib 页面操作，避免页码错位或重复添加。没有名字的旧批注在重放前赋稳定标识。

本次模块只在桌面版运行；浏览器预览显示入口与明确说明，不伪装成功。签名、加密、脚本和动态表单文件仍受现有保护。复杂文件批量兼容性未全面验收。

## 中文字体与原文重排的后续方案

本轮没有更换原文编辑内核，也没有宣称已完成段落重排。

1. **字库体积**：当前完整嵌入中文 OTF 是为了避开已经遇到的 CFF 子集损坏。下一步分别评估静态 TrueType 中文字体的子集路径与能正确处理 CFF 的子集工具。必须以 PDF.js 和 PDFium 独立渲染验证字形、文字提取、保存后再次编辑，不直接重新打开有问题的 CFF 子集开关。只嵌入实际使用字符，并保留字体许可信息。
2. **原位编辑字体**：把已有系统字体选择能力接入原文编辑，先检查字体是否包含新增字符；缺字提示替换。原字体可表示修改内容时继续沿用原字体。预览和导出必须采用同一测量和字体结果。
3. **段落识别**：借鉴上游按基线、间距、字体分组的思路，但加入栏边界、旋转和混合字体检测。只对能可靠识别的段落开放重排，复杂表格或多栏内容保留对象编辑。
4. **中文换行**：按 Unicode 字素与中英文断行规则处理，不能照搬上游按空格切词的实现。处理中英文混排、标点禁则、显式换行，并用实际字体度量计算行宽。
5. **边界和性能**：先限定在用户选中的文字框内重排；内容溢出显示提示，不自动推动整页其他对象。拖动宽度实时显示轻量预览，释放后才提交 PDF 修改，整段修改算一次撤销。

候选验收样本：简体、繁体、英文、数字金额、稀有字、标点、混合字号、多栏、旋转页、嵌入字体缺字，以及保存后再次修改。

## 已有验证与边界

- Rust 集成测试覆盖中文批注保存重开、旧无名批注删除后继续编辑、批注随页面排序/删除/旋转、XFDF/FDF 中文往返、合并提取后表单保留、图片降采样、保护文件拒绝、输出不覆盖和二进制请求边界。
- 前端测试覆盖页码范围、批注撤销/重做/序列化，以及二进制封装。
- `scripts/pdfcraft-verify.ts` 使用 PDF.js 独立读取并渲染 Rust 测试输出；验证页数、中文批注、表单 Widget 和再次通过 CANS 填写后保存。
- 浏览器检查了实际文字选择、工具面板和桌面版提示。完整 Windows 原生文件选择器交互、Acrobat/Foxit 兼容性、大文档性能和全量异常文件集仍待验收。

运行跨引擎检查前，使用环境变量 `CANS_PDFCRAFT_FIXTURES` 指向 `tests/output/pdfcraft`，执行 Rust 测试生成样本，再运行 `npx tsx scripts/pdfcraft-verify.ts`。

Gemini CLI 在本次上游审查时要求认证，未能提供分析结果；结论来自逐文件源码、测试阅读和本机验证。
