# 维护清理 · 2026-10-11

本轮整理已确认的维护负担，保留现有编辑与保存模型。

## 职责与类型

- `App.tsx` 从 2054 行减至 1381 行。文档加载、保存、草稿及 PDF 生命周期归入 `useDocumentSession`；文件选择、离开确认、窗口关闭及拖入事件归入 `useDocumentNavigation`。
- `useDocumentSearch` 管理延迟查询及过期结果取消；`useDocumentView` 管理缩放、滚轮定位和页码跳转。稳定回调共用 `useLatestCallback`。
- 页面侧栏、搜索、信息面板和表单控件提取为独立组件，App 保留工具状态与编辑命令的协调职责。
- PDF.js 的外部表单数据先经过 `formWidgets(unknown[])` 校验，再以可区分的文本/按钮/选择控件类型传入界面。排除非法坐标、未知字段类型、签名与普通按钮，保留文本、复选框、单选和选择项行为。真实 PDF 样本和异常数据新增 3 项测试。

## 样式和检查

- 合并 34 处重复或先基础后覆盖的规则，移除 99 条重复属性，`App.css` 从 1580 行降至 1408 行。保留独立的条件规则与较高优先级的组件变体。
- 计算样式对比发现并修正了归并时的侧栏标签底色、当前页缩略图底色和窄窗口页码条显示差异。首页及 1152 CSS 像素阅读界面的已采集属性一致；另检查了 720/1280 CSS 像素下的侧栏、工具栏和页码条状态。这不是所有交互状态的像素级等价证明。
- `tsconfig.check.json` 将测试和 TypeScript 辅助脚本纳入严格类型检查，接入 `npm run check`。修正了原先未检查到的坐标参数和字体资源断言；请求 mock 和文字提取断言去掉了不必要的 `any`。
- `@napi-rs/canvas` 声明为锁定版本的直接开发依赖。
- 固定输入保留在 `tests/fixtures`，生成 PDF、渲染图与既有浏览器输出迁至忽略的 `tests/output`。历史证据保留并更新引用，输出路径由共用辅助函数计算，约定见 `tests/README.md`。

## 范围边界

这次整理不等于“完全没有技术债”。App 仍协调多种编辑工具；完整段落重排、复杂 PDF 编辑、长文档内存基准、原生恢复故障演练仍有独立工作。未安装 hooks 专项检查器或改写第三方 Rust 源码。当前目录没有 Git 元数据，仍建议单独建立版本管理。

本轮直接运行程序的摘要见 `windows-maintenance-cleanup.json`。安装器及已运行的旧进程未替换；完整原生窗口交互并未重复验收。
