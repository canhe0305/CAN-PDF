# 兼容矩阵 — 开发预览

日期：2026-10-05。以下状态均只指本次验证范围，不代表白皮书产品 0.1 验收完成。

| 文件/能力                          | 行为                                   | 证据与限制                                    |
| ---------------------------------- | -------------------------------------- | --------------------------------------------- |
| 普通 PDF                           | 阅读、添加对象、导出                   | 合成三页样本；浏览器实际打开与导出            |
| 中文填写                           | 本地字体嵌入、缺字报错                 | PDF.js 独立读回中文；浏览器导出结果再次解析   |
| 常见 AcroForm                      | 文本、多行、复选、单选、下拉、列表     | 值与文本字段 AP 流自动测试；真实复杂表单待测  |
| 旋转页、CropBox                    | 统一 PDF 坐标                          | 4 旋转 × 4 缩放反向转换；PNG 实际渲染像素检查 |
| 页面调整                           | 无复杂结构时允许                       | 重排、旋转、删除和历史自动测试                |
| 表单/导航/批注页面调整             | 禁止                                   | 写入适配器二次校验，UI 同步禁用               |
| PNG 签名                           | 4 MB、4096 像素边长限制                | 写入渲染测试；异常图片仍需安全测试集          |
| 手写签名                           | 鼠标/指针绘制后作为透明 PNG 放置       | UI 实现；触控笔实体设备未验证                 |
| 扫描文件                           | 阅读和手动填写，零文字层有提示         | 尚无 50 页扫描压力测试                        |
| 混合文件                           | 按页读取现有文字                       | 未完成混合样本验收                            |
| 已有数字签名                       | 默认只读、尚未验证                     | 只有合成结构检测样本，无真实有效签名样本      |
| XFA/脚本                           | 只读                                   | 合成结构检测测试；绝不执行脚本                |
| 加密 PDF                           | 写入禁用；密码阅读暂缺                 | 未实现密码输入，也未完成加密文件样本测试      |
| 损坏文件                           | 解析失败时拒绝或只读                   | 有最小损坏样本；未建立完整损坏语料库          |
| 已有批注                           | 阅读画布保留外观，普通保存尽量保留结构 | 新批注编辑未实现；已有批注外观固定被拒绝      |
| 固定外观                           | 固定表单；应用新对象本身写入页面       | 自动测试表单移除；已有非表单批注拒绝导出      |
| 原生安全保存/草稿恢复              | 源码已写                               | Rust 编译、故障注入、实际桌面操作未验证       |
| Acrobat / 第二独立阅读器 / Preview | 待验收                                 | 不将 PDF.js 自动读取代替这些人工兼容检查      |

首次保存之外，同一会话的普通保存不重复叠加对象；跨会话可编辑对象恢复不在已交付能力内。缩略图展示源页面，尚未合成未保存覆盖对象。对象移动没有边界吸附；当前不支持图片签名旋转、文本对齐属性或标准高亮批注。

新增可选自带 API 翻译：配置 URL/模型/Key、连接测试、文字块确认、译文校对、原位覆盖预览与副本导出。只对白底横排简单文字进行试验，不承诺复杂论文版式；背景、公式、跨行语义和原文文字层保留等限制详见 `translation.md`。真实服务商与原生 HTTP 未验收。中文写入已改为完整字体嵌入，替代有字形损坏的 CFF 子集。
